# todo — a Git/GitHub practice project

A deliberately tiny to-do app. The code is not the point: it exists so you can
practise **branches, commits, pull requests, merge conflicts, tags and releases**.

👉 Start with **[GUIDE.md](GUIDE.md)** — it walks you through every step.

## Usage

```bash
python todo.py add "learn git"
python todo.py list
python todo.py done 1
python todo.py version
```

## Run the tests

```bash
python -m unittest -v
```
